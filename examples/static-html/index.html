Launch goals

  • Primary

    Clarify positioning

    Explain who the launch helps, what problem it solves, and how reviewers should evaluate the first draft.

  • Review

    Collect actionable comments

    Let reviewers pin comments to specific headings, cards, metrics, and copy blocks by using stable data-hrk-id anchors.

  • Handoff

    Prepare agent-ready edits

    Export comments as a copied prompt that includes selectors and source file context for a coding agent.

Review checklist

  1. Build the core package so the local AMD bundle exists.
  2. Open or serve this file in a browser.
  3. Enable review mode, add comments, then copy the prompt.

Local bundle initializer

The script below intentionally loads ../../packages/core/dist/html-review-kit-core.amd.js, the bundle produced by pnpm --filter @bharathnayak03/html-review-kit-core build.

HTML Review Kit keeps comments tied to stable artifact anchors so static HTML can move through review without a build step.
